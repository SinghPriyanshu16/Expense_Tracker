How categorization works

Transactions are categorized automatically using a few approaches, tried in order:

  1. If you've manually corrected a merchant before, that correction is used.
  2. The merchant name is matched against a database of known merchants.
  3. Keywords in the name are checked against category keywords.
  4. If nothing matches well, fuzzy string matching is used as a fallback.

You can click any category label in the transactions table to change it. The system remembers your corrections for next time.
